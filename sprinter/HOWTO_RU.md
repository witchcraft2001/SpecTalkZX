# SprinTalk 0.2.1 - руководство

Практическое руководство по SprinTalk, IRC-клиенту для Sprinter/DSS. Краткое
описание и список команд находятся в README (SPTALK.TXT).

## 1. Перед запуском: поднимите сеть

SprinTalk сам сеть не настраивает - он пользуется тем каналом, который в DSS уже
поднят. У каждой карты своя утилита подъема: она настраивает карту и публикует
текущие параметры (IP, gateway, DNS, а для Wi-Fi еще и
**скорость последовательного порта**) в окружение DSS, включая `NET=<тег>`:

```
Карта                         Утилита подъема        NET    DLL
----------------------------  ---------------------  -----  ------------
Wi-Fi / ESP (SprinterWiFi)    NETUP                  WIFI   UNETESP.DLL
RTL8019A ISA Ethernet         NETCFG -i, затем IFUP  RTL    UNETRTL.DLL
3Com 3C509B ISA Ethernet      NETCFG -i, затем IFUP  509B   UNET509B.DLL
```

Сначала запустите эту утилиту, потом `SPTALK`. Переменную `NET` вручную ставить
не нужно - ею распоряжается утилита подъема.

Дальше SprinTalk разбирается сам: читает `NET`, загружает подходящую
`UNETxxxx.DLL` **из своего каталога** - того, где лежит `SPTALK.EXE`, - и пишет
обе строки в окно сервера:

```
UNET: NET=509B -> UNET509B.DLL
Network ready via UNET509B.DLL (UNET509B v0.3.1)
```

Поэтому держите файлы `UNET*.DLL` рядом с `SPTALK.EXE`. Если загрузить не
удалось, SprinTalk печатает причину и продолжает работу без сети - интерфейс при
этом остается рабочим, см. раздел 14.

Для Wi-Fi скорость порта берется из того, что опубликовал `NETUP`, поэтому
SprinTalk использует ровно ту скорость, которую вы настроили там (115200, 57600,
230400, ...). Указывать ее в двух местах не нужно. У ISA-карт Ethernet скорости
порта нет вообще.

## 2. Экран

```
SprinTalk 0.2.1 UNET ::  #channel                         23:21:05   <- заголовок + часы
....................................................................
   область чата (история текущего окна)
....................................................................
nick:YourNick  [0 >1* 2! ]                                          <- строка статуса
уведомления / подсказки                                             <- желтая строка
> ваша строка ввода_____________________________________________    <- вводите здесь
```

Список окон в строке статуса: каждая цифра - открытое окно; `>` отмечает
текущее, `*` означает непрочитанную активность, `!` означает, что вас упомянули.
Окно `0` всегда является **серверным** окном (системные сообщения, notices,
ответы на команды).

## 3. Подключение

В серверном окне введите:

```
/server irc.libera.chat
```

Можно добавить порт: `/server irc.libera.chat 6667`. Дождитесь приветствия /
MOTD. Ваш ник и несколько последних серверов сохраняются в `SPTALK.CFG`; в
следующий раз нажимайте **Up**, чтобы выбирать последние строки `/server ...`,
и Enter для подключения.

Чтобы сменить ник: `/nick NewName`.

## 4. Каналы и окна

- **Войти на канал:** `/join #sprinter` - открывает новое окно и переключается
  на него.
- **Переключать окна:** **Ctrl+Tab** (следующее) и **Shift+Tab** (предыдущее).
- **Перейти к каналу:** **Alt+1..Alt+9** и **Alt+0** для 10-го. Каналы
  нумеруются с 1 в строке статуса (серверное окно показывается как `S`).
- **Tab** дополняет ввод: после `/` он дополняет **команду**, иначе - **ник**
  человека, которого SprinTalk недавно видел (это удобно для быстрого `/msg`
  или обращения к кому-то). Если подходит несколько вариантов, первое нажатие
  Tab вставляет общий префикс и показывает кандидатов в строке уведомлений;
  следующее нажатие Tab перебирает их.
- **Выйти с канала:** `/part` покидает канал в текущем окне.
- **Закрыть окно:** `/close` закрывает текущее окно - сначала делает `/part`,
  если это канал, или просто закрывает приватное окно. Серверное окно закрыть
  нельзя.
- **Говорить:** наберите сообщение и нажмите Enter. Ваши сообщения
  показываются как `<YourNick> text`. Сообщения других людей показываются как
  `<Their Nick> text`, причем каждый ник получает свой цвет (один и тот же
  человек всегда имеет один и тот же цвет).

Можно держать открытыми несколько каналов и приватных чатов одновременно.
Показывается только текущее окно, а остальные поднимают флаги `*`/`!` в строке
статуса.

## 5. Приватные сообщения

Есть два способа:

- **`/query <nick>`** - открывает пустое приватное окно для этого человека.
  Переключитесь в него и просто печатайте сообщения.
- **`/msg <nick> <text>`** - сразу отправляет одну приватную строку; приватное
  окно для этого ника открывается автоматически, и ваше сообщение отображается
  там. Если вы находитесь в другом окне, в строке уведомлений также появится
  подтверждение `-> nick`.

Когда кто-то пишет **вам**, приватное окно с его ником открывается само.

## 6. Действия: /me

`/me <action>` отправляет действие "от третьего лица". Если ваш ник Dimko,

```
/me waves hello
```

все (и вы тоже) увидят `* Dimko waves hello`. Используйте это для emote-сообщений.

## 7. NickServ и скрытие IP

В большинстве сетей вашей учетной записью управляет сервис **NickServ**, и для
использования зарегистрированного ника нужно идентифицироваться паролем.

- **Сохранить пароль:** `/pass yourpassword` - сохраняется в `SPTALK.CFG` и
  используется для **автоидентификации**: когда NickServ просит подтвердить ник
  после подключения, SprinTalk отвечает автоматически. (`/pass` без параметров
  показывает, задан ли пароль; `/pass clear` удаляет его.)
- **Идентифицироваться сейчас:** `/id` (использует сохраненный пароль) или
  `/id yourpassword`.

**Как скрыть IP от других пользователей.** Когда вы входите на канал, IRC-
**сервер** показывает ваш host/IP всем участникам - так устроен протокол, это
не утечка SprinTalk (сам SprinTalk не показывает чужие host). Чтобы скрыть
адрес, нужен **cloak** от сети:

1. Зарегистрируйте ник в NickServ (один раз). На Libera:
   `/msg NickServ REGISTER <password> <your-email>`, затем подтвердите кодом,
   который придет по e-mail: `/msg NickServ VERIFY REGISTER <nick> <code>`.
2. В SprinTalk выполните `/pass <password>`, чтобы идентифицироваться при
   каждом подключении.
3. Запросите cloak у сети (на Libera спросите в `#libera`). После выдачи ваш
   host будет выглядеть как `user/<account>` вместо адреса провайдера.

Примечание: SprinTalk идентифицируется сразу после подключения, поэтому дайте
автоидентификации пройти до `/join` - cloak применяется после идентификации.

> Безопасность: пароль хранится открытым текстом в файле `SPTALK.CFG`.

## 8. Кириллица и кодировка

Текстовый экран Sprinter использует **CP866**. Современный IRC обычно работает
в **UTF-8**. SprinTalk автоматически перекодирует текст в обе стороны, чтобы
русский текст был читаемым в публичных каналах: входящий UTF-8 -> CP866 для
показа, ваш ввод в CP866 -> UTF-8 при отправке.

Переключается командой **`/encoding`** (или `/enc`). Выключите перекодировку,
если канал уже использует CP866 или "сырые" байты.

## 9. Время, ignore, away

- **`/timestamp`** (`/ts`) - включает/выключает префикс `[HH:MM]` у сообщений.
- **`/ignore <nick>`** - скрывает сообщения от ника; `/ignore` без параметров
  показывает список игнорируемых ников; повторный `/ignore <nick>` удаляет ник
  из списка.
- **`/away [message]`** - помечает вас как away (без сообщения - вернуться).

## 10. Чтение истории

У каждого окна есть свой scrollback. **PgUp** / **PgDn** прокручивают текущее
окно вверх и вниз; прокрутите обратно в самый низ, чтобы вернуться к свежим
сообщениям.

## 11. Редактирование строки ввода

```
Up / Down       предыдущие / следующие введенные строки
Left / Right    переместить курсор
Home / End      перейти в начало / конец
Backspace       удалить символ перед курсором
```

Строка ввода прокручивается вбок, если она длиннее экрана (знак `<` показывает,
что слева есть скрытый текст).

## 12. Другие команды

Любая `/command`, которую SprinTalk не обрабатывает сам, отправляется на сервер
без изменений, поэтому обычные команды работают: `/whois <nick>`, `/names`,
`/list`, `/topic`, `/mode`, ... Их ответы появляются в серверном окне.
`/raw <text>` отправляет сырую IRC-строку.

## 13. Выход

Нажмите **Esc**, затем еще раз **Esc** для подтверждения (любая другая клавиша
отменяет выход). SprinTalk отправит `QUIT`, аккуратно закроет соединение и
вернется в DSS.

## 14. Диагностика проблем

- **"Run NETUP first" при запуске** - Wi-Fi не поднят; запустите `NETUP` и
  попробуйте снова.
- **"UI works, networking unavailable"** - драйвер не загрузился
  или канал не поднят. SprinTalk не завершается; строкой выше написана причина:
  - *"env NET is empty - run the card's setup tool first"* - вы не запустили
    утилиту подъема (раздел 1).
  - *"DLL not found next to SPTALK.EXE (or unreadable)"* - скопируйте файлы
    `UNET*.DLL` в тот же каталог, где лежит `SPTALK.EXE`. Строка `tried:` ниже
    показывает точный путь, который открывался.
  - *"DLL's own name does not match env NET"* - лежащая на диске DLL не та,
    которую требует `NET`; скопируйте свежий комплект `UNET*.DLL` поверх.
  - *"NETINIT failed - card present but not ready"* или
    *"DLL reports the link is down"* - карта не поднялась. Запустите утилиту
    подъема заново и посмотрите, что она пишет.
- **Не подключается / нет приветствия** - проверьте, что сеть действительно
  поднялась (штатной утилитой проверки из комплекта карты) и что имя сервера
  указано правильно.
- **"Connection lost" / "Connection timed out"** - соединение оборвалось
  (сервер закрыл его, или несколько минут не было данных и keepalive не получил
  ответ). SprinTalk отправляет PING серверу при простое и прекращает работу,
  если канал связи мертв; подключитесь снова через `/server ...`.
- `*** LINK NOT RESPONDING ***` в строке статуса - отправка не прошла
  (карта зависла или последовательная связь с ESP застряла). Проверьте карту /
  запустите утилиту подъема заново; сообщение исчезнет, когда данные снова
  пойдут.
- **Нечитаемый русский текст** - переключите `/encoding`.
- **Настройки** - сервер, порт, ник и пароль NickServ хранятся в `SPTALK.CFG` в
  текущем каталоге; удалите файл, чтобы сбросить настройки.
